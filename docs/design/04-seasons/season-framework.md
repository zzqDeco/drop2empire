# 赛季设计 I：赛季更替框架与重置/保留边界 (Seasonal Lifecycle & Reset Rules)

> **层级定位**：`04-seasons`（赛季设计层 · 跨赛季更替通则）  
> **职责边界**：严格区分**「跨赛季永久保留资产」**与**「单赛季周期性重置进度」**，定义一次性高阶装备蓝图 (`bp_*`)、本赛季安全保险箱 (`SafeBox`) 以及赛季限定绝版动态外观 (`cos_*`) 在赛季更替时的生命周期法则。

---

## 1. 为什么引入赛季制？

在自由市场与领土战争 MMO 中，若不进行周期性生产力洗牌，先发老玩家积累的无限人口、满级基建与垄断资金会让新入场玩家彻底丧失追赶空间。通过**赛季制（Season Cycle，每赛季 4~8 周）**：
1. **生产力与沙盘同一起跑线**：每个新赛季开启时，全服领主重新从荒原第一滴水起步，重温 Phase 1 破局竞速、重新抉择本赛季终身职业、争夺新赛季首张高阶蓝图定价权。
2. **外观与荣誉跨赛季永久沉淀**：玩家在往期赛季千辛万苦摸出或购买的**赛季限定动态外观 (`cos_*`)** 与 **唯一编号 UV 蚀刻藏品 (`S1-#xxxx`)** 永久保留并绝版，成为老玩家在新赛季起跑线上最耀眼的身份勋章。

---

## 2. 跨赛季「重置 vs 永久保留」严格边界表

| 资产/状态维度 | 赛季更替处理方式 | 设计依据与玩家体验说明 |
| :--- | :---: | :--- |
| **账号与社交身份 (`Handle`, `UserID`)** | **永久保留** | 玩家身份与邀请关系跨赛季恒定 |
| **赛季限定动态外观 (`cos_*` 库存与穿戴状态)** | **永久保留 · 绝版升值** | 往期赛季（如 S1）外观在新赛季开启后停止荒原掉落，仅能通过玩家间现货市场 (`BID / ASK`) 交易流通，具备长期收藏价值 |
| **唯一序列号 UV 蚀刻藏品 (`Collectibles`)** | **永久保留 · 绝版升值** | 带有 `S1-#000001` 印记的典藏圣物永久陈列于个人藏品馆 |
| **聚落人口、物资、技术、建筑数量、改良与工程** | **赛季重置** | 清除经营进度与资源发现记录，恢复初始 4 个住房；重新体验建设循环 |
| **终身职业选择 (`Profession`) 与工坊设备槽** | **赛季重置** | 允许玩家在 S1 玩科学家、S2 改玩炼金术士或工匠，体验不同分工视角 |
| **金币余额 (`GoldBasis`) 与宏观货币账本** | **赛季重置** | 彻底清零历史通胀，恢复新赛季初始 `500 G` 宝藏启动金与做市商锚定汇率 |
| **荒原局外整备已研习蓝图 (`LearnedBlueprints`)** | **本赛季有效（跨赛季重置）** | 玩家在 S1 销毁 1 张 `bp_*` 学会的打造配方，在 **S1 全赛季内可无限次用基础资源打造**；进入 S2 后随新赛季装备池更新而重置 |
| **荒原未研习蓝图库存 (`bp_*` in Inventory)** | **本赛季有效（跨赛季重置）** | 鼓励玩家在当季积极研习自用或挂单出售变现，不囤积功能性数值图纸跨赛季碾压 |
| **本赛季安全保险箱等级 (`SafeSlotCount: 1→5 格`)** | **本赛季有效（跨赛季重置）** | 一旦在当季打造出 3 格【墨械密码保险箱】或 5 格【泰坦次元保险箱】，**当季所有荒原对局永久生效且死亡不掉落**；新赛季恢复初始 1 格暗袋 |
| **商会领土战沙盘与积分 (`WarState`)** | **每 7 日小结算 / 跨赛季重置** | 每 7 个战争日决出周冠军商会，赛季末结算赛季总霸主 |


## 3. 重置过程的状态一致性

赛季重置同时清除生产毫秒余量和产出小数余量，战争周期基线设为当前已到期边界，防止新赛季继承旧周期或分数时间。玩家持久版本号继续递增，避免旧网络响应覆盖重置后的状态；订单与成交序号继续递增，历史审计不被覆盖。活跃远征和近期回执随当季整备一起清空，旧 ID 在新赛季一律拒绝。玩家行与全服宏观状态在同一事务内重置；部署时不得混用迁移前后的写入程序。

建设命令序号在重置时递增，最近命令签名清空；旧请求不能在新赛季重放。外观、藏品与账号保留规则不变。
