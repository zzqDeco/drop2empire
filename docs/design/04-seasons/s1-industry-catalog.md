# S1 产业与职业数值目录

本目录与 `profession_consumables.go`、`economy_catalog.go` 同步。数量是完整实物单位，运行时乘 1,000；时间为现实秒/分钟。公司参考价不是固定市场成交价。所有目录调整需重跑 [经济仿真](economy-calibration.md)。

## 职业设施

四职业一级：水 500、木 250、石 180、铁 40、炭 30。二级：水 1,500、木 750、石 540、铁 120、炭 90；或任一公司作业包 ×4，加上述普通材料的 80%。二级制造时间 ×80%，上限两级。无金币入门费用，基础工坊与职业选择为前置。

产量不变。原料缺货后需股东选择路线与适当预算/售价；替代不承诺在原售价下仍有利润。
