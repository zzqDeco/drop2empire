# 整体设计 I：核心愿景、设计支柱与渐进式叙事 (Vision, Pillars & Progressive Disclosure)

> **层级定位**：`01-overall`（整体设计层 · 跨赛季恒定公理）  
> **职责边界**：定义《滴水成城》(Drop to Empire) 跨所有赛季永恒不变的核心体验支柱、零剧透信息披露铁律、视觉美学规范与九章史诗叙事脉络。不涉及单赛季专属道具池或具体微观数值表。

---

## 1. 核心定位 (High-Concept Pitch)

**「从荒原岩缝掬起第一滴水，到构建跨职业工业帝国、深入多区块裂隙摸金撤离、统帅商会铁骑争夺黑曜王座。」**

《滴水成城》融合了四重递进的游戏乐趣：
1. **静谧而有呼吸感的单人开局（A Dark Room 式渐进披露）**：第 0 秒全屏仅有一枚【打水】按钮与微光叙事，不向新手倾倒任何复杂面板。
2. **高度耦合的聚落工业链（Frostpunk / Factorio 式政令与转化）**：水、木、炭、石、燧石、残片互为上下游，仓储上限与满仓虹吸冲矿迫使玩家思考动态调配。
3. **高风险高回报的 2D 多区块传送门「搜 · 打 · 撤」肉鸽（Extraction Roguelite）**：消耗聚落过剩基础物资，深入四座传送门互联的荒原区块，在实时沙暴倒计时内读条搜刮一次性高阶装备蓝图与极低爆率赛季限定动态外观。
4. **严谨守恒的宏观自由市场与商会领土战（EVE / Albion 式经济驱动战争）**：四大终身职业互锁分工，所有高阶蓝图、赛季动态外观、工业制品均可在中央限价订单簿 (CLOB) 自由交易，并最终转化为每晚 20:00 结算的双商会图结构城池争夺战。

## 2. 四大永恒设计支柱 (Core Design Pillars)

| 支柱编号 | 支柱名称 | 核心设计准则 | 违背红线（严禁出现的设计） |
| :---: | :--- | :--- | :--- |
| **P1** | **零剧透渐进披露**<br>*(Progressive Disclosure)* | 玩家未触及对应阶段前，绝不提前渲染未解锁的按钮、资源行、岗位栏或市场面板。UI 随世界认知同步生长。 | 严禁在开局阶段展示锁定的灰态商城、复杂的战争沙盘或满屏未解锁词条；严禁打水按钮因新元素出现而发生位移闪现。 |
| **P2** | **单向消耗与经济隔离**<br>*(Economic Boundary Isolation)* | 聚落产线产出大宗基础资源；荒原肉鸽与领土战争**单向消耗**基础资源，仅产出不可生产的蓝图、外观与荣誉，绝不回吐海量水/木/石冲击主城产线。 | 严禁在肉鸽或开箱中投放大量基础水/木/石导致主城人口与基建失去意义；严禁出现「100% 必掉传世外观」的破坏市场型道具。 |
| **P3** | **外显荣誉与实机投射**<br>*(Visible Prestige & Identity)* | 玩家千辛万苦摸出或交易获得的赛季动态外观，必须**同时常驻显示在个人 Profile 衣橱栏**与**2D 肉鸽地图实机移动棋子**上。 | 严禁将稀有外观做成仅躺在背包格里的静态图标或纯数值加成卡片。 |
| **P4** | **纸墨工程制图美学**<br>*(Blueprint & Ink Precision)* | 全站遵循古典墨械工程蓝图视觉 (`tokens.css`)，所有动态数字强制使用等宽表格数字 (`.mono-num`)，确保高频跳动零抖动。 | 严禁使用未经 Token 定义的刺眼霓虹色或非等宽数字导致布局横向抽搐。 |

## 3. 零剧透渐进披露与九章史诗叙事脉络

### 3.1 序章固定锚点交互 (`Population == 0`)
当玩家初入荒原（`人口 == 0`）时，界面采用 **3-Slot 垂直黄金锚点布局 (`opening-stage`)**：
- **上槽 (`opening-top-slot`)**：四幕微叙事随水位递进浮现（`干涸荒原` $\rightarrow$ `微光初现` $\rightarrow$ `旅人驻足` $\rightarrow$ `聚落起点`），首次点击后平滑淡入水位进度条。
- **中槽 (`opening-center-slot`)**：【打水】主按钮**绝对居中锁定**，点击瞬间绽放水波涟漪与上浮粒子，无论上下槽如何显隐，按钮坐标零偏移。
- **下槽 (`opening-bottom-slot`)**：积满 10 滴水瞬间，【招募第一位居民 (-10 水)】卡片在预留槽位内平滑淡入。

### 3.2 纪元叙事九章递进表 (`story-chronicle-bar`)

招募首位居民进入主界面后，顶部纪元指引条随玩家里程碑自动演进：

| 章节 | 章节标签 | 触发条件 | 叙事文本与解锁的界面模块 |
| :---: | :--- | :--- | :--- |
| **序章** | `序章 · 干涸荒原` | `人口 == 0` | 干涸的荒原，万籁俱寂。唯有岩缝深处，尚存一缕微弱的水脉。（仅显示【打水】按钮） |
| **第一章** | `第一章 · 初立营火` | `人口 >= 1`，未解锁【最初的居所】 | 第一位居民已拎起木桶自动汲水（`+2.0/秒`）。继续积攒 30 滴水，在右侧解锁【最初的居所】。（展开【资源】与【发展】双栏） |
| **第二章** | `第二章 · 居所生根` | 解锁【最初的居所】 | 居所立起屋檐，手点打水翻倍（`+2/次`）且伴生燧石。招募满 3 名居民，解锁【斧头蓝图】。 |
| **第三章** | `第三章 · 伐木开林` | 解锁【斧头蓝图】 | 石斧已铸成！【岗位】面板正式展开，调派居民采集木材。（展开中间【岗位】分配栏） |
| **第四章** | `第四章 · 水木并进` | 伐木上岗，未解锁【采石技术】 | 林间响起伐木声。扩建【深井蓄水池】与【荒原斥候营】，开启荒原搜打撤与游商易物。 |
| **第五章** | `第五章 · 破岩采石` | 解锁【采石技术】 | 山麓岩脉已探明！调派居民开采筑城石料，并在【砖砌炭窑】烧制高能木炭。 |
| **第六章** | `第六章 · 工坊奠基` | 采石上岗，未解锁【基础工坊】 | 水、木、炭、石四脉齐备。启用【聚落政令】与【虹吸冲矿槽】，集齐物资建造【基础工坊】。 |
| **第七章** | `第七章 · 远古遗物` | 解锁【基础工坊】 | 工坊炉火彻夜不息。锻造【高压水阀】【承压木框】【铭文石板】，开启【神秘的宝藏】。 |
| **第八章** | `第八章 · 圣坛择业` | 解锁【神秘的宝藏】，未选职业 | 远古宝藏轰然开启！择定你的终身职业，步入跨职业贸易与商会战争纪元。 |
| **第九章** | `第九章 · 滴水成城` | 选定四大职业之一 | 聚落已蜕变为帝国重镇。在下方工坊制造专属制品、挂单现货市场，率军争夺黑曜与白银城池。 |
