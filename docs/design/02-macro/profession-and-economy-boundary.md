# 宏观设计：职业分工与经济边界

## 职业的长期价值

四职业的专属能力是制造资格。科学家、炼金师、魔法师、工匠各有两级专属设施、三种可交易易耗品；任何职业都能购买使用。耗材覆盖个人生产、建设、探索和公会战争。职业不会强制绑定某家公司，也没有“个人负责供料，公司负责收购”的任务关系。

职业入口延续研究 → 实际建造基础工坊 → 三个工程部件 → 装配 → 选择职业。装配不发金币。职业制造从零金币可以启动，仍需支付设施和每批实物成本。职业资格不赠送设施；设施升级也不能用研究解锁替代付款。

| 职业 | 一级 → 二级设施 | 个人用途 | 协作用途 |
| --- | --- | --- | --- |
| 科学家 | 机巧工坊 → 动力实验室 | 过载电池、便携探测器 | 火控校准包 |
| 炼金师 | 蒸馏工坊 → 催化实验室 | 工业触媒、恢复药剂 | 战地救护包 |
| 魔法师 | 铭文工坊 → 符阵工场 | 定向符印、闪步卷轴 | 守城结界 |
| 工匠 | 精锻工坊 → 工程装配坊 | 精锻刀具、破障工具 | 工事包 |

旧永久增产设备和军备配方继续作为补充分支，不能通过旧 `crafting/craft` 接口绕过耗材设施、队列或序号。具体成本属于 [S1 产业目录](../04-seasons/s1-industry-catalog.md)，使用机制属于 [职业耗材](../03-micro/profession-consumables.md)。

## 公司独占资产

个人不能制造公司设施、导能合金、稳定晶材、重载/精密单元或作业包。公司由策划按目录稀缺引入，上市资金来源于玩家已有金币。公司之间通过订单簿采购形成多层供应链，替代路线以更多材料或时间换取可选性；个人仍可持有、转卖所有商品。

个人职业升级提供普通材料路线，公司的终端产品是另一种建设/制造投入选择。某家公司停产不会阻断新玩家从零发展；公司产品的实际价值来自成本和时间收益，不能靠永久保底买单维持。

## 荒原边界

荒原仍是独立、受时间限制的搜打撤玩法。它消耗聚落资源，产出不可生产的战术掉落、一次性蓝图、极低概率季节外观，不反向供应普通资源或公司资产。新增四种可制造探索耗材只进入远征消耗，不进入稀有掉落池，也不能延长沙暴、保证外观或跳过未探索危险格。
