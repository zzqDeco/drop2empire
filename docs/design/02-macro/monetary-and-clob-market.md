# 宏观设计：货币联盟与真实限价订单簿

本版用于已批准的清档重开。运行中的内容赛季更替保留金融资产；清档上线不是赛季按钮的别名。数值见 [S1 产业目录](../04-seasons/s1-industry-catalog.md)，上线步骤见 [操作手册](../../operations/economy-clean-start.md)。

## 发行权与账户

金币精度为 1 Gold = 10,000 Basis，实物为 1 单位 = 1,000 Milli，账户余额不用浮点数累加。

```
存量 = 累计获准发行 - 累计正式注销
     = 玩家可用 + 玩家买单托管 + 财政国库 + 联盟准备金
       + 公共采购可用/托管 + 公司可用/托管 + IPO 托管 + 旧 NPC 余额
```

新经济所有货币账户初始为零，旧 NPC 余额恒为零，无虚构挂单或成交。公会展示的捐款累计是财政国库内部标记，不能重复计入货币总量。商品存货、股价、市值及未实现利润不是金币。

只有策划的货币联盟可以发行/注销，入口同时受管理隧道、管理员身份和政策编号保护。单政策金额与当前货币存量上限 100,000,000 Gold，防止溢出及失控配置；累计发行可高于存量。政策 ID 为 3–80 字符；同 ID 同内容重放不再执行，同 ID 改内容拒绝。政策与资产变动、追加审计在同一数据库事务提交，审计失败全部回滚。

| 政策 | 真实变化 |
| --- | --- |
| `issue` | 获准发行至联盟准备金，增加存量 |
| `fund_public` / `fund_treasury` | 从准备金划拨公共采购 / 财政预算，存量不变 |
| `procure` | 公共账户使用自己的现金挂基础商品或职业制品买单；不能买公司产品或股票托底 |
| `withdraw_order` | 撤回公共账户指定订单，释放未成交托管 |
| `consume_public` | 消耗已经买到的公共实物库存，金币不变 |
| `recall_public` / `recall_treasury` | 回笼可用现金至准备金，不能取走订单托管 |
| `cancel` | 仅注销准备金中已有金币，减少存量，累计注销递增 |

玩家从自己的生产、挂价与成交获得金币。新手装配古代装置、选择职业、公司 IPO、自动生产均不铸币。财政津贴只花已拨预算或税收，不足则按现有战争结算规则支付，不能回退到自动增发。

## 交易规则

所有参与者共用 CLOB：玩家、公共采购账户、公司。买单全额冻结金币，卖单全额冻结已有实物/股份。价格优先，同价按单调订单序号优先；成交用挂单价，退还买方改善价格的差额，所有主体禁止自成交。数量须为整数单位/整数股。每主体最多 128 笔开放单，全服最多 10,000 笔。满载时公司自动采购/挂售暂停，玩家仍可撤单。

卖方每笔成交支付 `floor(成交额 × 1%)`，全额进入财政国库。旧设备/军备制造的 2 Gold 费用也全额入财政，职业耗材制造不收金币。交易税、手续费不是正式注销。

市场初始最新价/开盘价为空；第一笔真实成交才产生行情。参考价只是策划成本试算，不代表存在买家、保底售价或官方回购。玩家直接在市场报价，公司按需求、可成交深度、成本及可用现金采购，没有指定个人供应商或定向供货任务。

## 不变量与审计

每次全服事务保存前验证：货币总量一致、各账户现金非负、买单托管等于剩余买单价值、冻结实物等于剩余卖单数量、IPO 资金等于有效认购额、上市公司总股份等于全部玩家可用/冻结股份之和。股份不可拆成零碎股。

`d2e_economy_audit` 追加保存政策、IPO、投票事件；`d2e_trades_audit` 保存每笔撮合。UI 历史窗口可截断，审计不截断。公司采用历史加权平均存货成本；销售时才确认收入和成本，IPO 资金不计利润。
