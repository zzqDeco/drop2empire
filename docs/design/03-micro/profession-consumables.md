# 微观设计：职业设施、制造与耗材使用

## 制造与节奏

选定职业只解锁资格与原有职业被动，不赠送设备、军备、材料或活动点，需另建一级设施。一个个人队列，单请求 1–20 批；入列时一次性校验并扣足全部材料，产物在队列完成时一起交付，不支持取消退款。二级设施制造时间减少 20%，一级不收金币。队列使用聚落确定性秒时钟及八小时离线补算上限，轮询频率不影响产出。

过载电池与工业触媒互斥、不能叠加补充。使用时要求已有空闲职业设施，激活五批额度；排队时只对前五个实际制造批次应用并消耗额度，后续批次恢复基础成本。电池时间乘 80%、用水乘 120%；触媒各配方原料乘 90%，按 Milli 向上取整。二级时间收益和电池相乘。加速不产生自动利润，必须有需求才值得消费。

## 使用落点

| 制品 | 行为 / 限制 |
| --- | --- |
| 过载电池 / 工业触媒 | 在职业工坊仓库使用，作用于下一制造队列 |
| 定向符印 | 要求采石岗位有人；600 个有采石工的生产秒内，石材产出 ×80%，采石伴生物 ×150%；无工人暂停计时 |
| 精锻刀具 | 已建聚落设施的下一次单座重复建设普通材料 ×90%；首建/多座不消耗，扣料失败保留效果 |
| 工事包 | 已入公会者启用，下一次后勤物资捐献或新建公会驻地普通材料 ×92%；失败保留，成功消耗 |
| 火控校准包 | 自己已出兵的节点，己方阵营本轮不利克制系数向 1.0 缩减一半 |
| 战地救护包 | 同条件，己方本轮战损率减 5 个百分点，最低零 |
| 守城结界 | 自己已出兵且己方拥有的节点，本轮防御加成加 8 个百分点 |
| 恢复药剂 | 远征内回复 30 生命，上限为最大生命；满血拒绝且不扣物 |
| 便携探测器 | 远征内揭示周围四格，不生成战利品 |
| 破障工具 | 对当前未完成宝箱读条剩余时间 ×60%，不能跳过整个读条或用于撤离 |
| 闪步卷轴 | 正交移动两格，两格均须已探索、可通过、无未击败敌人；校验移动冷却并重设读条 |

战争支援按“节点 + 阵营 + 道具”每轮各限一次，结算后清除。本版作用于该节点己方阵营，不是只加强使用者自己的单位。界面节点选择不能越过服务端的出兵/阵营校验。

四种远征耗材每种每局一次，走 `raidId + commandSeq`，相同请求重放不重复扣物。只扣安全的局外库存，不添加到撤离战利品；沙暴到期拒绝使用，永不延长远征期限。

移动与使用耗材成功后，客户端按返回位置和 `channelRemainingMs` 同步搜索计时：破障立即采用缩短后的剩余时间，闪步落到未开启宝箱时开始搜索，离开宝箱时清除旧计时。落到撤离点不会自动发起撤离，仍需玩家点击信标。

## 公司终端作业包

重载包与精密包由公司独占制造，可交易。个人二级职业设施可用四包替换 20% 普通建设材料，普通材料路线一直存在。

公司每条产线使用一个包覆盖五个实际批次：重载缩短时间 20%，精密降低普通原料 10%，公司中间品投入不打折。每批摊销 1/剩余批数的未摊成本，最后一批吸收舍入余数。重载仅在真实买单积压且预计增量贡献覆盖耗材价格时采购；精密仅当五批节省值覆盖包成本时采购。不划算或买不到则用基础配方，不能以“已选耗材”强迫亏损生产。

## 界面信息

职业制造、现货、公司股权为三个页签，公司未被策划引入前隐藏公司页签。库存中为零的职业/公司制品不占主城资源表。职业选择后撤掉永久“聚落进展”横幅；普通成功信息五秒消失。IPO 开启/配售/退款、股东投票开启/结果以可确认弹窗展示，详细记录留事件日志，同一设备按账号记录逐条已读 ID，在当前保留的事件中从旧到新逐条确认；同一时刻的事件也有独立递增 ID。日志仍只保留最近 40 条，因此不是无限期可靠消息队列；持股、认购及未结束投票始终能在公司页查看。


制造界面按输入的实际批数展示总材料、总产物和总时间，区分剩余额度内的加成批与普通批，采用与服务端相同的逐批定点取整。材料不足时区分「先扩仓」「安排生产或购买」「积攒中 + ETA」；队列忙碌、批数非 1–20 整数或未建产线时不能提交。工事包、精锻刀具、符印的待用状态持续可见；战争节点选择仅在仓库有战争耗材时出现。

现货市场的单价、盘口回填及总额保留四位小数；数量按整数单位提交，不静默舍入。无金币时默认卖出，余额/库存不足会说明原因并禁用提交。输入总额超过 JavaScript 安全整数范围时要求拆单，服务端继续独立执行全部范围、资金与托管校验。成交税按每笔成交向下取整，因此界面不承诺按整单估算的税后净额。
